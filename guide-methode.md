# 🧭 Guide de méthode — Comment apprendre le français efficacement

Ce guide accompagne les 5 niveaux du parcours. Il explique **comment** étudier,
pas seulement **quoi** étudier.

---

## 1. Les 5 clés d'un apprentissage réussi

1. **La régularité** — 20 à 30 minutes chaque jour valent mieux que 3 heures le
   dimanche. Le cerveau apprend par répétition espacée.
2. **La lecture à voix haute** — elle travaille la prononciation, le rythme et la
   compréhension en même temps.
3. **Le carnet de vocabulaire** — un mot nouveau = une fiche : *le mot + sa
   nature + un exemple de phrase*.
4. **L'écriture** — on ne retient vraiment que ce qu'on réutilise. Écris chaque
   jour quelques phrases.
5. **La révision active** — ne relis pas passivement : cache la réponse, essaie
   de te souvenir, puis vérifie.

---

## 2. Un planning type (débutant à intermédiaire)

| Jour | Activité (20–30 min) |
|------|----------------------|
| Lundi | Nouveau vocabulaire (10 mots) + phrases |
| Mardi | Grammaire / conjugaison (une règle) |
| Mercredi | Lecture d'un texte + questions |
| Jeudi | Révision du vocabulaire de lundi |
| Vendredi | Petite rédaction (5–10 lignes) |
| Samedi | Écoute (chanson, vidéo) + lecture à voix haute |
| Dimanche | Repos ou révision libre |

---

## 3. La méthode du carnet de vocabulaire

Modèle de fiche :

| Mot | Nature | Sens | Exemple |
|-----|--------|------|---------|
| *ramasser* | verbe | prendre ce qui est par terre | *J'ai ramassé une feuille.* |
| *la joie* | nom (fém.) | sentiment de bonheur | *La joie illuminait son visage.* |

> 💡 Révise ces fiches selon la **répétition espacée** : jour 1, jour 3, jour 7,
> jour 15, jour 30.

---

## 4. Comment lire un texte (à tous les niveaux)

1. **Première lecture** : comprendre le sens général (ne t'arrête pas à chaque mot).
2. **Deuxième lecture** : souligne les mots inconnus, devine-les grâce au contexte.
3. **Vérifie** : cherche les mots-clés dans un dictionnaire.
4. **Reformule** : résume le texte en une ou deux phrases avec tes propres mots.
5. **Réponds aux questions** de compréhension.

---

## 5. Les erreurs fréquentes à éviter

| Erreur | Correction |
|--------|------------|
| « Je *suis allé* » vs « j'ai allé » | ✅ *aller* se conjugue avec **être** : « je suis allé » |
| Oublier l'accord de l'adjectif | ✅ « une robe **verte** », « des chats **noirs** » |
| Confondre *a* / *à* | ✅ *a* = verbe avoir ; *à* = préposition |
| Confondre *ou* / *où* | ✅ *ou* = choix ; *où* = lieu |
| Confondre *ce* / *se* | ✅ *ce* = déterminant ; *se* = pronom (se laver) |
| Oublier le *-s* du pluriel | ✅ « les livres », « des amis » |

---

## 6. Ressources pour progresser

- **Lire** : albums (débutant), contes, romans jeunesse, puis classiques.
- **Écouter** : chansons françaises, podcasts lents, journaux pour apprenants.
- **Parler** : lire à voix haute, répéter des dialogues, se filmer.
- **Écrire** : journal quotidien, résumés, lettres.

> 🎯 **Règle d'or** : sors de ta zone de confort d'**un tout petit peu** à chaque
> fois. Un texte trop facile n'apprend rien ; un texte trop dur décourage. Vise
> le niveau « je comprends 80 %, je devine 20 % ».
